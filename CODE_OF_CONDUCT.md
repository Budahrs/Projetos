# Código de conduta

Este projeto adota o [Contributor Covenant, versão 2.1](https://www.contributor-covenant.org/pt-br/version/2/1/code_of_conduct/).

Em resumo: trate todos com respeito, critique ideias e não pessoas, aceite revisões com boa-fé e ajude quem está começando. Assédio, ofensas e exposição de dados pessoais de outras pessoas não são tolerados.

Problemas de conduta podem ser relatados em particular aos mantenedores pelo perfil [@Budahrs](https://github.com/Budahrs) no GitHub. Os relatos são tratados com sigilo.
