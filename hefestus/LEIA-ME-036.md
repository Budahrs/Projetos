# Hefestus 0.36

Implementação de 19/10/2026. Instalação original atualizada; o atalho em Meus Projetos continua válido. Recarregue o editor para carregar a versão 0.36.0.

- Opções > Layouts da faixa e acesso pelo botão direito na faixa.
- Salvar layouts nomeados neste navegador, aplicar, excluir, importar/exportar JSON versão 1.
- Restaurar padrão recomendado e desfazer/refazer a última alteração de layout.
- Layout inclui acesso rápido, guias ocultas, grupos fixados/recolhidos e organização da faixa. Não altera o documento.
- Menus com Home/End, Tab para fechar e foco inicial em ação habilitada.
- Mais informa a quantidade de comandos adicionais nos grupos simples.
- Backup dos módulos anteriores em work/hefestus-antes-036.

Não foram executados testes nem validação interativa, por solicitação do usuário. Foi realizado o empacotamento para atualizar o arquivo aberto pelo atalho. Os demais itens do plano continuam pendentes; este incremento não conclui todos os critérios de Ribbon/layouts.

## Padrão permanente de decisões do projeto

Usar projetos consolidados como referência, consultar documentação oficial aplicável e registrar padrões aproveitados e adaptações. Neste incremento: Microsoft Office/Windows Ribbon, acesso rápido personalizável, guias e ações contextuais. Layouts nomeados são uma extensão do Hefestus.
